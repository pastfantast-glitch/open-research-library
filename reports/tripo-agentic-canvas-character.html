01 / PURPOSE

測試目的

本次使用的提示詞

要求完成分件、低多邊形 Smart Mesh、UV、紋理與組裝，保留獨立物件及 T-pose，提供預覽和匯出；若可選則使用 2K 貼圖。這份指令沒有指定數值面數，本輪不包含綁骨或動畫。

閱讀原始完整提示詞
請依照我上傳的角色設定圖，完成「角色分件生成 → 組裝」流程，目標是可供後續遊戲資產製作的動漫女性戰士。

【外觀基準】
以設定圖為唯一外觀依據，保留鳴潮風格的動漫質感、粉色側分長髮、藍綠色眼睛、白色高領無袖外衣、深色內搭、棕色肩帶與腰帶、單側肩甲、單側深色長袖、藍色露指手套、棕色短褲及高筒戰靴。
保留圖中的身形及腿長比例，不要自行重新設計。
不要披風、武器、劍鞘，也不要新增配件。
肩甲、長袖與配件的左右位置必須對照設定圖，不要鏡像顛倒。

【姿勢】
維持正面全身 T-pose：雙臂在肩膀高度水平伸直，雙手張開，雙腿伸直並略微分開，腳尖朝前。
頭部、軀幹與腳掌朝向一致，避免歪頭、扭腰或動態姿勢。

【分件規劃】
請先評估以下分件方式，提出可執行的生成與組裝計畫：
1. 角色基底：頭部、頭髮、頸部及四肢，並以貼身內搭與短褲覆蓋軀幹及骨盆。
2. 白色高領外衣：包含附著其上的肩帶、腰帶、扣件與口袋。
3. 單側肩甲。
4. 單側深色長袖與雙手手套：若獨立生成不利於對位，可整合至角色基底，但請先說明。
5. 左右高筒戰靴。

小型扣件與裝飾整合到所屬部件，不要拆成大量零件。各部件只生成一次，避免基底與外加部件重複出現相同服裝或配件。

【生成要求】
各部件使用一致的人體比例、T-pose、朝向與尺寸基準，保留可供組裝對位的位置。
優先使用 Smart Mesh，採適合後續編修的低多邊形設定；若可選，使用 2K 貼圖。
保持一致的動漫材質與色彩，避免把強烈陰影或高光直接畫入貼圖。
如果上述功能或設定無法使用，請先說明可用方案。

【組裝要求】
分件完成後，使用 AI 3D Lab 或目前可用的組裝功能，依設定圖組裝成完整角色。
檢查肩甲、袖子、手套、衣領與戰靴的對位，修正明顯穿插、浮空、縫隙及比例不一致。
保持原有 T-pose，並保留各部件的獨立物件結構，方便後續編修。
保留分件結果及組裝結果，提供正面、側面與背面預覽供檢查。

本次先完成分件、組裝及模型匯出，不進行綁骨或動畫。

請先列出最終分件清單、執行順序及可確認的點數資訊，等我確認後再開始生成；需要額外重試或新增付費生成時，也請先告知。

第一次詢問：確認可修改、刪除的分件清單。研究者選擇繼續。

確認項目：頭部與粉色長髮、素體、無袖長外套與腰部束帶、棕色短褲、雙棕色長靴、雙藍色露指手套、角色左臂黑色長袖與肩甲，共 7 項。

當下發現：文字規劃與清單雖同為 7 項，內容已改為頭部與短褲獨立、雙靴與雙手套各成一項、肩甲與長袖合併。

2.4 元素提取：產出分件設定

操作與執行：確認清單後，元素提取節點從單張角色圖生成獨立的 2D 分件參考，畫布出現 7 條分支。節點中央的家具與角色是功能示意。

本步產出：7 張部件設定圖，作為接下來的模型生成輸入。

當下發現：素體參考已包含頭部、頭髮、淺色衣褲，與獨立項目存在重複範圍；深色高領內搭則包含在外衣參考。

第二次詢問：Tripo 提出低多邊形 Smart Mesh 計畫，列出 T-pose、比例、朝向與材質一致性等要求。研究者按「繼續」。

模型產出：7 項分件參考各自連接至模型輸出，畫布已顯示各部件灰模。

本步產出：各部件模型的線框截圖。

當下發現：可見髮束、扣件、拉鍊、靴子束帶與肩甲細節，素體也仍包含完整頭部及衣褲外形。後續檢視的節點設定為四邊面、目標 10,000 面、生成數 1、紋理關閉。

2.6 UV 展開與檢視

展開前確認：7 項模型產出後，Agent 要求檢查輪廓、比例、對位、破洞與變形，再繼續 UV 展開。

操作與回覆：模型確認後，各分支新增 UV 節點。Agent 回報 UV 已展開，詢問接縫位置、覆蓋範圍與貼圖空間是否合理，下一步預計生成紋理。

本步產出：研究者開啟 7 項 UV 檢視，記錄佈局與介面統計。長袖與肩甲的重複截圖只收錄一次。

貼圖前詢問：計畫要求依設定生成一致的動漫材質，並列出「先修正臉部 UV 問題後再貼圖」。研究者確認後繼續。

當下發現：短褲變成淺米色，手套增加橄欖綠、卡其與金色，黑袖出現膚色漸層；素體也帶有外衣、腰帶、手套及長袖圖案。外衣正面主要配色較接近設定。畫面沒有呈現先完成臉部 UV 修復的證據。

2.8 進入 AI 3D Lab 組裝

進入 Lab 前的交接：Agent 請研究者檢查色彩與接縫，提供 Lab 入口，將臉部 UV 修正及整體組裝轉交 Lab。

操作：送出「依照對位進行組裝」，要求對齊接口與方向、避免穿插及間隙，保留部件形狀。

系統詢問：Lab 表示六個檔案都置中於原點，沒有共同對位座標，目前尚未修改；詢問以 #25 T 字姿勢角色為基準組裝全部裝備，或只處理 #28 長靴。研究者選擇 T 字姿勢角色。

第一次組裝產出：取得完整角色正面預覽。外衣與靴子大致就位，但角色左臂可見深色袖子與膚色兩條輪廓，雙手疑似重疊或錯位。

2.9 回饋與修正

研究者回饋：「目前組裝起來看起來跟設定不一樣」。Lab 承認自行估算比例、僅檢查人體對位，沒有核對設定圖，並更正先前的完成表述；要求補充設定或具體差異，以 #31 組裝模型為基礎修正。

第二次組裝產出：外衣下襬較收窄，腿部露出範圍增加。左臂、手套及配色問題仍可見，沒有取得本輪完整修改指令與模型量測。

第三次組裝產出：再次取得正面預覽，取景較遠。左臂與手部的疑似重疊輪廓仍未排除；畫面大小變化不足以證明模型比例已修好。

流程停點：本次記錄到第三版正面預覽。研究者另回報三次修正共約 139 點；組裝截圖版次與計費修改次數分開記錄。

05 / IMPROVEMENTS

問題與改善建議

將流程中發現的問題與下一次可採取的做法放在一起。以下改善建議尚未重新實測，需先確認工具能力與報價。

問題與本次證據下一次的改善做法
分件範圍重複：素體已有頭髮、頭部與衣褲，另生成相同部位（E42–E48）。生成前決定保留素體頭部或使用獨立頭部，逐件列出保留、替換、遮蔽範圍，確認高領內搭歸屬。
面數未明確約束：提示詞只寫低多邊形；節點顯示 10,000 四邊面目標（E50）。聊天室明列各部件面數與全角色總預算，區分四邊面與三角面。研究者觀察未指定時常以一萬四邊面為基底，不能當成所有版本的固定預設。
UV 修正順序未落實：貼圖前要求修臉，貼圖後又交給 Lab（E26–E27）。在紋理前確認 UV 修復結果，保留佈局及棋盤格畫面；檢查臉部完整性、四肢內側接縫、拉伸、重疊、像素邊距與 texel density。
紋理偏色與重複服裝：棕短褲、藍手套、黑袖偏離設定，素體再帶服裝圖案（E28–E34）。每個部件一起提供原設定及分件參考，寫明指定色彩與材質範圍；檢視彩色近照後再組裝，不先推定是 UV 或演算法造成。
解析度要求與節點不同：原要求可選 2K，後來畫面選中 4K（E52）。生成前核對解析度及去光選項，輸出後讀取實際檔案尺寸與貼圖通道；不能由彩色預覽推定有 Normal 或完整 PBR。
缺共同座標、未核對設定：Lab 回報皆置於原點，後承認自行估算比例（E36、E38）。一起交接設定圖、完整資產清單、基準角色與不採用部件；先確認單位、朝向及資產映射，再核對肩線、腰線、衣襬與靴口。
手臂／手套疑似錯位，完成回報不等於驗收（E37、E39、E40）。固定相機檢查各輪結果，補肩腕近照及側背面，匯出原檔檢查重複幾何、穿插和間隙；分開記錄執行完成與品質合格。
扣點與修改缺少逐筆紀錄：餘額、對話標記和節點報價無法完全對帳。每次確認、重試及修改都記錄前後餘額、範圍、耗時與產出 ID；以作業項目與已確認單價記帳，再與逐筆扣點及整輪餘額核對。

06 / CONCLUSION

測試結論與附件

本次使用心得

Agentic Canvas 能把單張角色圖串成分件參考、模型、UV、紋理與組裝流程，畫布和控制模式讓中途確認有跡可循，適合早期概念驗證與分件雛形探索。

本次仍需人工確認部件範圍、配色與對位。流程跑完後沒有直接達成角色資產驗收；下一輪優先明列面數、分件歸屬與 Lab 交接內容，再檢查原始模型及貼圖。

本報告能判斷的範圍

這是一次角色、單張正面設定與一次流程及後續修正的紀錄，沒有跨工具或多角色實驗。截圖能證明可見外觀與介面讀值；平台回報另外標示，未經原檔檢查的項目不視為通過。

未取得模型與貼圖原檔、完整帳務及精確耗時，無法確認最終三角面數、幾何連通性、貼圖接縫或動畫品質，也不計算現金成本或效率。三版組裝的取景不同，不能由像素量測尺寸變化。本次亦未進行 Base Color 轉 Normal 實驗。
